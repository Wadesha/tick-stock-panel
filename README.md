# A股量化交易 · 19关实战训练系统

**在线体验**: https://wadesha.github.io/tick-stock-panel

基于真实A股行情数据的闯关式量化投资学习平台。从市场扫描到全自动交易，19个关卡覆盖完整投资框架。

## 技术栈

- **前端**: 纯HTML/CSS/JavaScript，单页SPA，暗色交易风格UI
- **后端**: Python Flask，腾讯财经API实时数据
- **数据源**: 腾讯财经 (qt.gtimg.cn) 实时行情 + K线数据

## 19关实战路线

| 关卡 | 主题 | 操作 |
|------|------|------|
| 1 | 市场情绪扫描 | 扫描50只热门股，判断涨跌比/赚钱效应 |

| 4 | 均线金叉选股 | MA5/MA10/MA20趋势跟踪 |
| 5 | 估值选股 | PE<15/PB<2价值洼地发现 |
| 6 | 动量选股 | 涨幅>3%强势股追踪 |
| 7 | 超跌反弹 | 跌幅>3%逆向投资机会 |
| 8 | 换手率异动 | 资金活跃度监测 |
| 9 | 多因子评分 | 4维度综合评分系统 |
| 10 | 构建投资组合 | 等权重组合构建 |
| 11 | 风险敞口分析 | 振幅/换手率风险量化 |
| 12 | 动态止损 | ATR波动率止损设置 |
| 13 | 凯利公式仓位 | 最优仓位计算 |
| 14 | 趋势跟踪策略 | 双均线系统 |
| 15 | 均值回归策略 | 超卖反弹抓取 |
| 16 | 行业轮动分析 | 板块强度对比 |
| 17 | 策略回测验证 | 历史数据检验 |
| 18 | 模拟实盘交易 | 真实行情模拟买卖 |
| 19 | 全自动量化系统 | 完整自动化交易面板 |

## 快速启动

```bash
pip install flask flask-cors
python3 backend.py
# 访问 http://localhost:5888/
```

## 后端API

| 接口 | 说明 |
|------|------|
| `GET /api/market-scan` | 市场扫描（涨幅榜/跌幅榜/涨停） |
| `GET /api/stock-quote?code=600519` | 个股实时行情 |
| `GET /api/batch-quotes?codes=600519,000001` | 批量行情 |
| `GET /api/kline?code=600519&count=60` | K线数据 |
| `GET /api/technical?code=600519` | 技术指标（MA/MACD/RSI/KDJ） |
| `GET /api/stock-screener` | 条件选股 |
| `GET /api/search?q=茅台` | 股票搜索 |

## 数据说明

所有行情数据通过腾讯财经API实时获取，无需API Key。

- 交易日 9:30-15:00 获取实时数据
- 非交易时间获取最近交易日数据
- 数据延迟约3-5秒
